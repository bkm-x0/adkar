# Adkar App - تطبيق الأذكار

تطبيق حديث لعرض الأذكار الإسلامية اليومية من السنة النبوية.

## المميزات

✨ **عرض منظم للأذكار** - أذكار الصباح والمساء وأذكار أخرى
🔍 **بحث قوي** - البحث عن الأذكار بالنصوص والفوائد
📂 **تصنيفات** - تصفية الأذكار حسب الفئة
📱 **تصميم متجاوب** - واجهة جميلة على جميع الأجهزة
🎤 **قراءة بصوت** - الاستماع للأذكار
📋 **نسخ سهل** - انسخ النصوص بسهولة
⏱️ **عداد ذكي** - احسب مرات الذكر

## البدء

### المتطلبات
- Node.js (v16 أو أحدث)
- npm أو yarn

### التثبيت

```bash
# تثبيت المكتبات
npm install

# تشغيل التطبيق في وضع التطوير
npm run dev

# بناء التطبيق للإنتاج
npm run build

# عرض التطبيق المبني
npm run preview
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub إذا لم يكن موجودًا هناك.
2. افتح Vercel واختر New Project ثم استورد المستودع.
3. اترك الإعدادات الافتراضية كما هي. Vercel سيستخدم `npm run build` ويخرج إلى `dist` تلقائيًا.
4. بعد النشر، أي تحديث يدفع إلى الفرع الرئيسي سيُعاد نشره تلقائيًا.

## البنية

```
src/
├── components/
│   ├── Header.jsx          # رأس الصفحة
│   ├── CategoryFilter.jsx  # مرشح التصنيفات
```

## التقنيات المستخدمة

- **React 18** - مكتبة JavaScript للواجهات
- **Vite** - أداة البناء والتطوير
- **Tailwind CSS** - إطار عمل CSS
- **Lucide React** - أيقونات SVG
